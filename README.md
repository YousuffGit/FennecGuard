# PasswordManager

A modern, secure password manager featuring a desktop client and a browser extension.

## Architecture & Security
This project is currently under active development. The security model is being built from the ground up prioritizing memory safety, cryptography, and zero-trust local storage.

### Tech Stack (Planned)
- **Core Engine:** C# (.NET 10)
- **Desktop UI:** WPF
- **Browser Extension:** TypeScript
- **Database:** SQLite encrypted via SQLCipher

### Completed Milestones
- [x] **Phase 1: Cryptography Sandbox** - Implemented authenticated encryption using AES-256-GCM.
